PROJECT WALKTHROUGH

Try team notes in a private Git repository with a synthetic decision.

  1. Try before you wire

    In a disposable checkout, connect a private test brain. Review generated hook and instruction files before committing them; team members must consent before real sessions are shared.

    ganjineh init --brain git@example.com:team/test-brain.git --area backend
ganjineh doctor

  2. Look up a sample decision

    Add a made-up note and find it from a second checkout. Search is lexical, so compare results using words that actually appear in the note.

    ganjineh note --help
ganjineh search --pull refund screen

  3. Use the opt-out before confidential work

    The scrubber is not an access policy. Keep the brain private and use #private in a prompt to exclude a sensitive session rather than relying on automatic masking.

راهنمای عملی پروژه

یادداشت‌های تیمی را در یک مخزن خصوصی با تصمیمی ساختگی امتحان کنید.

  1. پیش از اتصال واقعی آزمایش کنید

    در نسخهٔ آزمایشی، حافظهٔ خصوصی را وصل کنید. فایل‌های تنظیمات را ابتدا بررسی کنید و پیش از اشتراک نشست‌های واقعی رضایت اعضا را بگیرید.

    ganjineh init --brain git@example.com:team/test-brain.git --area backend
ganjineh doctor

  2. تصمیم ساختگی را پیدا کنید

    یادداشتی ساختگی اضافه کنید و در نسخهٔ دوم مخزن جست‌وجو کنید؛ جست‌وجو واژه‌محور است.

    ganjineh note --help
ganjineh search --pull refund screen

  3. پیش از کار محرمانه ثبت را غیرفعال کنید

    پالایش خودکار جایگزین کنترل دسترسی نیست. مخزن را خصوصی نگه دارید و برای نشست حساس از ‎#private‎ استفاده کنید.
