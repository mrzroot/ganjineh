## Team brain (gonjineh)

Teammates' finished AI sessions are stored as short notes in a shared git repo. Before you build or assume something is missing (an endpoint, a component, a decision), search it:

- `gonjineh search "<words>"` or the MCP tool `search_memory`
- `gonjineh who <path>` or `who_knows_about` to find who touched a file
- If a note contradicts the code, trust the code and tell the user.
- Write `#private` in a prompt to keep a session out of the brain. Never put secrets in prompts.
